Generador de videos de chat

Arma videos verticales (9:16) que simulan una conversación de chat con IA — teclado, mensajes, respuesta y captura — con audio sincronizado, a partir de un guion de texto simple.

En desarrollo

Por ahora se usa desde la terminal

El motor (React + Remotion) ya está armado y andando en video-chat-prisma/, pero todavía no está conectado a esta web — hoy hay que generar el video corriendo estos comandos en la carpeta del proyecto: 

cd video-chat-prisma
npm install
npm start        # vista previa en el navegador
npm run render   # genera out/video.mp4

La próxima etapa es justamente subir el guion desde acá y descargar el .mp4 directo, sin pasar por la terminal.

Formato del guion

Una acción por línea, los tiempos en segundos:

usuario escribe (2s): lo que el usuario tipea
usuario envia
chat responde (3s): lo que "dice" el chat
captura
banner (4s): el cierre — promoción de Consultora Prisma

El guion activo está en video-chat-prisma/public/guiones/actual.txt — para generar otro video, se reemplaza ese archivo y se vuelve a correr npm run render.
